### Earring Store

A custom-built virtual catalog designed to showcase and sell handmade earrings. Developed with Python and Django, this web application 
features a session-based shopping cart, an intuitive admin dashboard for inventory management, and a smart sorting algorithm that 
prioritizes available items. The checkout process redirects seamlessly to a pre-filled message on WhatsApp to finalize the order. 
Built with Tailwind CSS for a responsive, minimalist UI.
